# 💋Elli Beauty
I detta projekt har jag skapat en fiktiv webbplats från grunden. Elli Beauty är en webbplats byggt på tre sammanlänkade sidor och rikar sig till skönhetsintresserade personer. 
## Tekniker 
- HTML
- CSS
- JavaScript

## Funktioner
- Responsiv design anpassad för både mobil och dator
- Interaktiv mobilmeny via JavaScript
- Kontaktformulär med integrerad JavaScript-validering
- Tydlig struktur med CSS Grid och Flexbox
